Multi-Stage Resume Parsing Pipeline Architecture

How your document is spatially extracted, normalized across 1,000+ skills, and structured for ATS scoring

Transparent & Explainable
Step 1
Multi-Format Ingestion & Text Extraction

Dedicated extractors handle visual layout, coordinate sorting, and text cleanliness:

  • 2-Column Layout Sorting (PDF): Calculates midpoint (mid_x = page.width / 2) and sorts blocks column-by-column by vertical position (y0), eliminating cross-column text scrambling.
  • Embedded Link Extraction: Scans PDF annotation objects (page.get_links()) to extract clickable LinkedIn, GitHub, and portfolio URLs.
  • Scanned PDF Check: Flags scanned or image-only documents when character count falls below 50.
  • DOCX & Text Formats: Parses paragraphs and table cells with whitespace stripping.
Step 2
Information & Section Segmentation

Deterministic NLP heuristics segment the extracted text into logical sections:

  • Contact Info: Standard regex for email, international telephone patterns, candidate name heuristic, and location patterns.
  • Career Timeline: Tenure calculation extracting calendar years (1990–2026), role progression, and measurable bullet points.
  • Education & Degrees: Pattern heuristics for accredited degrees (B.Tech, B.E., B.S., M.S., M.Tech, MBA, Ph.D) and affiliated universities.
  • Projects & Certifications: Tech stacks, GitHub repositories, and industry credentials (AWS, Azure, GCP, PMP, Scrum Master).
Step 3
Three-Tier Universal Skill Normalization

Comprehensive dictionary covering 1,000+ technical, cloud, AI, and data competencies:

  • Word-Boundary Matching: Uses boundary regex ((?<!\w)skill(?!\w)) to prevent substring collisions (e.g., prevents matching "go" inside "algorithm").
  • Canonicalization: Normalizes variants into standard names: postgres → PostgreSQL, react.js → React, k8s → Kubernetes, sklearn → Scikit-Learn, golang → Go, rest → REST APIs.
  • Domain Categorization: Groups skills across Languages, Frameworks, Cloud & DevOps, Databases, AI/ML, and Analytics.
Step 4
Structuring & Scoring Engine Handoff

The parsed data is structured into a clean ResumeData object and passed to:

  • ATS Resume Scorer: Calculates your Intrinsic Resume Quality Score (0–100%) across Contact (10%), Skills (30%), Experience (20%), Education (15%), Projects (15%), and Certifications (10%).
  • Job Matching Engine: Evaluates vacancies via explainable compatibility formula:
    M = 0.35S + 0.20E + 0.15K + 0.10P + 0.10L + 0.10Q
